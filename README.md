# MadoAI のサポートと規約

Google Play が求める 2 枚（サポート・プライバシーポリシー）を置く場所。
**アプリのソースは別のリポジトリ**（非公開）で、ここには HTML になる文書しか
置かない。

```
index.md        入り口
support-ja.md   サポート        日本語
support-en.md   Support         英語
privacy-ja.md   プライバシー     日本語
privacy-en.md   Privacy Policy  英語
```

## 直すときは

**本文の出所は本体リポジトリの作業記録にある。** あちらはコードと突き合わせて
書いてある（スマートフォンのアプリが INTERNET の権限を持たないこと、PC のアプリの
頁が外への通信を止めていること、広告・解析の SDK が入っていないことなどを確認済み。
主張ごとの根拠の表つき）。**ここだけ直すと食い違う**ので、元を直してから移すこと。

## 連絡は Issues で

利用者からの連絡窓口を兼ねている。素っ気ない 1 枚を置くより、実際に書き込める
場所があるほうが伝わる。
